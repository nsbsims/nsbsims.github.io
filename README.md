# nsbsims.github.io

Home page for the NSB science simulations: https://nsbsims.github.io/

Each subject lives in its own repository and is published at `nsbsims.github.io/<repository name>/`:

| Subject | Repository | Address |
|---|---|---|
| Chemistry | [nsbsims/chemistry](https://github.com/nsbsims/chemistry) | https://nsbsims.github.io/chemistry/ |

## Adding a subject

1. Create a repository named after the subject (for example `physics`), put its pages in it, and turn on GitHub Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
2. Edit `index.html` in this repository and add an entry to the `SUBJECTS` list near the top of the script. A commented-out Physics example is already there.
